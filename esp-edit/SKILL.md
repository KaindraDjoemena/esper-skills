---
name: esp-edit
description: Handles modifying and editing existing code safely and predictably.
---
<esper_module type="skill">
  <name>esp-edit</name>
  <purpose>This skill is used for making precise edits to existing files in a repository while ensuring the surrounding codebase is not inadvertently broken.</purpose>
  <instructions>
<execution_steps>
<step>Understand the modification requirements before making changes.</step>
    <step>Review the context of the files that will be edited.</step>
    <step>Apply edits iteratively. Prefer small, localized changes over sweeping rewrites.</step>
    <step>Verify that the syntax remains correct and that the logical flow is uninterrupted.</step>
    <step>Provide a summary of the edits that were made.</step>
</execution_steps>
</instructions>
</esper_module>
