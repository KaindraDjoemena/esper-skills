# esp-edit

## Purpose
This skill is used for making precise edits to existing files in a repository while ensuring the surrounding codebase is not inadvertently broken.

## Instructions
1. Understand the modification requirements before making changes.
2. Review the context of the files that will be edited.
3. Apply edits iteratively. Prefer small, localized changes over sweeping rewrites.
4. Verify that the syntax remains correct and that the logical flow is uninterrupted.
5. Provide a summary of the edits that were made.
